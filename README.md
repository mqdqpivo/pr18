# Task Manager SPA

Небольшое SPA приложение для управления задачами, разработанное в рамках Практической работы №18.

## Стек технологий

*   **React** (v18) - Библиотека пользовательского интерфейса
*   **TypeScript** - Статическая типизация
*   **Redux Toolkit** - Управление состоянием (Store, Thunks, Slices)
*   **React Router DOM** (v6) - Маршрутизация и защита роутов
*   **Tailwind CSS** - Утилитарный CSS фреймворк для стилизации
*   **React Hook Form** - Работа с формами и валидация
*   **Axios** - HTTP клиент
*   **JSON Server** - Mock API

## Требования

*   Node.js (v16+)
*   npm или yarn

## Установка и запуск

1.  **Установите зависимости:**

    ```bash
    npm install
    ```

2.  **Запустите Mock API сервер:**

    Откройте новый терминал и выполните:

    ```bash
    npm run server
    ```

    API будет доступно по адресу `http://localhost:3001`.

3.  **Запустите приложение:**

    В другом терминале выполните:

    ```bash
    npm run dev
    ```

    Приложение откроется по адресу `http://localhost:5173`.

## Функционал

### Аутентификация
*   Вход в систему (используйте `admin@example.com`, пароль любой).
*   Mock-токен сохраняется в `localStorage`.
*   Защита приватных маршрутов (`ProtectedRoute`).

### Задачи
*   Просмотр списка задач.
*   Фильтрация (Все / Активные / Завершенные).
*   Поиск по названию.
*   Создание новой задачи (валидация полей).
*   Редактирование задачи.
*   Удаление задачи (с подтверждением в модальном окне).
*   Отметка выполнения задачи.

### UI/UX
*   Адаптивная верстка (Mobile / Desktop).
*   Индикаторы загрузки.
*   Обработка ошибок.
*   Современный дизайн с использованием Tailwind CSS и иконок Lucide.

## Структура проекта

```
src/

└── main.tsx        # Точка входа
```
