# Отчет по практической работе №18
## Тема: «Реализация небольшого SPA (Single Page Application)»

**Цель работы:** Изучить принципы построения одностраничных приложений с использованием библиотеки React и языка TypeScript, освоить управление глобальным состоянием приложения через Redux Toolkit, настроить клиентскую маршрутизацию с помощью React Router DOM и реализовать взаимодействие с имитацией серверного API для выполнения CRUD операций.

**Ход работы:**

Разработка приложения началась с инициализации проекта с использованием сборщика Vite, который обеспечивает быструю среду разработки. Были установлены и настроены необходимые зависимости, включая React Router для навигации, Redux Toolkit для управления данными и Tailwind CSS для стилизации интерфейса. Был создан файл конфигурации базы данных `db.json` для эмуляции бэкенда.

Рисунок 1 — Структура проекта и установленные зависимости в package.json

Далее была реализована архитектура взаимодействия с сервером. С помощью библиотеки Axios был настроен HTTP-клиент, который автоматически добавляет токен авторизации к запросам. Для управления пользователями был создан Redux-слайс `authSlice`, отвечающий за вход в систему и хранение состояния авторизации. Была сверстана страница входа с валидацией формы, а также настроен компонент защиты маршрутов, который перенаправляет неавторизованных пользователей на страницу логина.

Рисунок 2 — Страница авторизации и код слайса аутентификации

Основной функционал приложения сосредоточен на управлении задачами. Был разработан `tasksSlice` в Redux, который обрабатывает асинхронные запросы к серверу для получения, создания, обновления и удаления задач. На главной странице был реализован компонент списка задач, который поддерживает фильтрацию по статусу (все, активные, выполненные) и поиск по названию. Интерфейс позволяет пользователю наглядно видеть состояние каждой задачи.

Рисунок 3 — Главная страница со списком задач и фильтрами

Для реализации создания и редактирования задач был создан переиспользуемый компонент формы. Он используется как на странице создания новой задачи, так и на странице детального просмотра. При редактировании поля формы автоматически заполняются текущими данными. Для безопасного удаления задач было внедрено модальное окно, запрашивающее подтверждение действия у пользователя, что предотвращает случайную потерю данных.

Рисунок 4 — Страница редактирования задачи и модальное окно удаления

В завершение работы была добавлена информационная страница "О приложении" и доработана навигационная панель. Весь интерфейс был адаптирован для корректного отображения на мобильных устройствах и десктопах. Были исправлены ошибки взаимодействия с `json-server`, в частности, переведен middleware на формат CommonJS для корректного запуска в среде Node.js.

**Вывод:**

В ходе выполнения практической работы было успешно разработано и протестировано одностраничное приложение "Task Manager". Были закреплены навыки построения архитектуры React-приложения, использования типизации TypeScript для повышения надежности кода и управления сложным асинхронным состоянием через Redux Toolkit. Реализованный функционал полностью покрывает требования технического задания, включая авторизацию, маршрутизацию и CRUD-операции с данными.
